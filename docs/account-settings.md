# 账户设置界面

Go + Wails 版沿用原生版的服务商选择与配置流程，让个人邮箱与使用自有域名的企业邮箱都能选择正确预设。界面仅编排现有账户命令，凭据由后端保存，编辑账户不会读回密码。

```mermaid
flowchart LR
    A[添加邮箱] --> B[选择服务商]
    B --> C[邮箱、授权码与显示名称]
    C --> D[自动填写服务器]
    D --> E{是否手动修改}
    E -->|否| F[后端按服务商候选验证]
    E -->|是| G[使用手动服务器配置]
    F --> H[验证成功后保存并同步]
    G --> H
```

- 服务商选择保持旧版两列入口与顺序，并复用代码绘制的服务商图标。返回服务商列表保留已输入的基本信息。
- `account.detect` 预填服务器；过期结果与手动修改后的结果不覆盖当前配置。新增账户未手动修改服务器时不发送覆盖值，保留后端候选探测。验证失败保留表单并展开服务器设置。
- 编辑页将基本信息、IMAP、SMTP 与签名分区，密码留空表示保持原凭据。保存通过 `account.update` 执行。
- 设置弹窗固定为 800 × 680 CSS 像素，切换菜单不改变外框位置和尺寸。小窗口按可用视口限制高度，内容独立滚动并预留滚动条位置。
- 添加与编辑弹窗分别使用 680 × 650、760 × 720 的外框，底部操作栏保持可见；窄窗口中字段与服务器分区改为单列。

入口：`frontend/src/settings.tsx`、`frontend/src/account-dialog.tsx`。状态与持久化规则见 `internal/engine/commands.go` 中的 `accountCommand`。
