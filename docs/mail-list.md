# 邮件列表

Go + Wails 界面由 `frontend/src/mail-view.tsx` 实现，数据和变更通过 Go 命令引擎。

- 默认紧凑双行列表：48px 行高，上行发件人与日期，下行主题；未读、主题组计数、红旗和附件图标保留。
- 按今天、昨天、本周等日期分组；紧凑模式隐藏正文摘要和头像，优先展示更多邮件。
- 主题归类、组内导航、多选、搜索、按时间排序仍由引擎处理。
- 三栏直接占满窗口客户区；不在邮件列表或阅读区外再套圆角卡片。
- 两条栏间分隔线可拖动，宽度保存到偏好。工具按钮、搜索和行选择提供稳定可访问名称与控制标识。

运行 `make demo` 检查实际界面；控制通道截图的能力边界见 [control-protocol.md](control-protocol.md)。

账户标题按完整邮箱地址显示，单行超宽省略并可悬停查看完整地址；提供商标记以 IMAP/SMTP 主机优先识别，邮箱域名作为回退，支持自定义域名企业邮箱。
