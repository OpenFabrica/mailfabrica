# 检查与安装更新

1. 在工具栏右侧菜单选择“检查更新”。
2. 有新版本时点击“下载并自动安装”，窗口显示下载、校验和准备进度。
3. 完成后应用自动退出，替换文件并重新启动，不需要拖动应用或手动覆盖文件。

适用于 macOS 和 Windows/Linux portable。请先保存或关闭尚未保存的写信窗口；应用也会检查下载期间的新输入。关闭更新弹窗后任务继续，重新打开可查看进度。

macOS 请从已安装到 Applications 或其他可写目录的应用启动，不要从打开的 DMG 中执行更新。Windows/Linux 请在当前用户可写的目录运行。目录不可写时更新会报告错误，旧应用继续运行。

更新不会替换邮箱数据、账户或钥匙串。替换或新版启动失败时会恢复并重启旧版显示错误。网络失败、包不完整、平台不匹配或 macOS 发布者验证失败时不会安装，可以重试。

0.1.0/0.1.1 的旧更新按钮仍是“下载并打开安装器”；这些版本需要先安装含自动替换能力的新版，之后的升级即可自动完成。也可从 [官方发布页](https://github.com/OpenFabrica/mailfabrica/releases) 下载。
