# 检查与安装更新

1. 打开工具栏右侧菜单，选择“检查更新”。更新窗口显示当前版本和检查结果。
2. 有新版本时，查看更新说明，点击“下载并打开安装器”。窗口显示下载进度；随后自动检查文件完整性、Apple 签名与发布者。
3. 验证通过后会打开 DMG。将 MailFabrica 拖入 Applications，并确认替换旧版本。退出 MailFabrica，再从 Applications 启动新版。

邮件与账户存储在应用包之外，替换应用不会删除邮件。更新窗口关闭后，已开始的任务继续执行；重新打开更新窗口会显示当前任务与结果。需要重复打开安装器时，点击“打开安装器”，应用会再次验证下载文件。

网络失败时可以重试检查或下载。没有可用的本机安装包、摘要不匹配或 Apple 验证不通过时，应用不会打开文件。当前自动下载支持 macOS；安装由用户完成，不会自动替换或重启正在运行的应用。

也可从 [官方发布页](https://github.com/OpenFabrica/mailfabrica/releases) 手动下载安装包。
