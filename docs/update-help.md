# 检查与安装更新

在设置中选择“应用更新”，点击“检查更新”。有新版时可查看发布说明，再下载对应平台的安装包。应用只查询官方发布源，并核对文件大小和 SHA-256。

## macOS

正式安装到 Applications 或其他可写目录的 Go 版应用支持下载、校验、正常退出后替换并重启。还会校验 Apple 发布者和 Gatekeeper，保留启动参数与自定义数据目录。

退出前请保存写信内容；存在未保存邮件或正在发送时，界面会阻止直接交接。没有正常退出的提交标记时，辅助进程不执行替换。新版成功启动后才清理更新备份。

从 DMG 中运行或使用开发二进制时，请手动安装。首次从 0.1.5 及更早版本迁移时也需手动安装，保留原数据目录。

## Windows 与 Linux

下载并校验后，退出应用，解压并替换程序文件，保留数据目录。当前 Go 版的 portable 包不自动替换或重启，安装包也不签名。

更新不会主动替换账户、邮件原文或凭据存储。网络、文件完整性或发布者验证失败时会显示错误，可重新检查或从[官方发布页](https://github.com/OpenFabrica/mailfabrica/releases)下载安装包。

实现和交接规则见 [updates.md](updates.md)。
