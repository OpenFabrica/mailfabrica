# 邮件正文阅读

macOS 版默认用系统浏览器显示 HTML 邮件，保留表格、按钮、媒体查询和邮件配色。
顶部的 HTML / 纯文本切换不影响邮件原文；正文可以滚动、选择文字和复制。

远程图片默认开启。可在“设置 → 阅读”中关闭“自动加载远程图片”；这是所有账户共用的全局设置，
保存后当前正文会重新加载，换信和重启后仍保留。写信窗口的原文引用也遵循该设置。
邮件自带的 CID 图片不受这个开关影响。加载远程图片会向发件人的图片服务器发出请求。

若 HTML 无法显示，阅读器会提示“HTML 预览不可用，已显示纯文本”，并提供“重试”。
超出 2 MiB 的 HTML 继续使用纯文本阅读；文字不等待远程图片下载；若正文加载超时，可切换纯文本或重试。
邮件中的脚本、表单、自动跳转和网页下载不会执行；点击链接由系统打开。

Windows/Linux 与写信窗口中的原文引用仍采用原有渲染方式。
