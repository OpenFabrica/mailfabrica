# 邮件阅读

Go MIME 解析器产生纯文本、HTML 和附件视图。界面使用 Wails 的系统 WebView，在禁止脚本的 iframe 中排版正文；邮件不作为应用组件渲染。

- 远程图片默认开启；设置中的“自动加载远程图片”经 `app.prefs {remoteImages}` 保存。
- CID 图片由后端映射为受限数据 URL，不依赖外部网络。
- 移除脚本、内嵌框架、表单、活动事件属性等，并施加正文 CSP。
- 可通过阅读菜单切换 HTML/纯文本；下载和解析错误可见，可重试。
- 文本选择、复制和滚动由 WebView 提供；固定自动化入口见[控制协议](control-protocol.md)。
- 界面三栏直接铺满客户区。邮件默认 48px 双行列表，摘要默认隐藏；列表菜单可切换紧凑模式，按主题归类仍然保留。

`ui.screenshot` 只导出应用 DOM，不包含 iframe；正文排版必须用实际浏览器或窗口图像验证。

## 聚合邮件

打开聚合组后，可点开其中任意一封，在专用工具条中用“组内上一封／下一封”连续阅读；旁边显示当前位置。普通列表导航使用左右箭头，组内导航使用上下箭头，仅在聚合邮件中显示。

点“一键 AI 汇总”使用设置中的现有 AI 服务，读取组内正文后生成时间线、结论与待办；不发送附件、不修改邮件或自动回复。未下载的正文会先取回。当前一次最多 200 封、正文与上下文合计 512 KiB，超限会明确报错，不默默截取。组内邮件变化后需重新汇总。

发件人、收件人、抄送姓名和主题中的 MIME 编码词会自动解码；已有缓存也即时按同一规则显示，无需重新收取邮件，原始 `.eml` 不被改写。

## 正文链接

阅读与引用中的静态 HTTP、HTTPS、mailto 链接由父页面监听用户点击后交给宿主，由系统浏览器/邮件应用打开。浏览器开发预览在新标签打开。正文不自行弹出新窗口，不执行邮件脚本；`javascript:`、`data:`、`file:` 及其他活动协议在渲染与宿主两端拒绝。页内 `#anchor` 保留在正文内跳转。

这包含常见营销邮件里的取消订阅链接：外观为灰色不代表禁用，实际是否可打开取决于静态链接地址。打开链接后的订阅操作由对应网站处理，客户端不自动代为提交。

macOS WebKit 在 iframe 禁脚本时也会拒绝正文文档内的 JavaScript 事件回调，因此桌面版在可信父页面按静态链接的可见位置建立点击区域，不开放 `allow-scripts`。滚动及排版变化时更新位置，真实指针点击时再次命中正文，避免使用旧位置的链接。文字选择与非链接区域的滚动仍由原正文文档处理。
